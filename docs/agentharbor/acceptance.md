# AgentHarbor 最小验收与本机部署方案

整理日期：2026-11-07
状态：A 机本机上传与导入已验收；A、B 双机 M01–M05 尚未验收

本轮使用一个项目、两台机器上的两个 Codex 来源，验证真实任务采集、定时同步和记忆跨机复用。第一版的记忆服务已确定为腾讯 MemoryCore；M04 必须通过实际运行的 MemoryCore 完成。同一种适配器在两机分别运行，仍需分别识别其机器与会话来源。以本机 A 模拟云端，机器 B 接入；通过后再将 A 上的服务迁移到云服务器。

本文是[完整需求文档](requirements.md)的阶段验收补充，只规定本轮最小通过条件，不取消完整需求中的其他目标。两机 Codex 的实施顺序见[第一版实施方案](codex-first-release-plan.md)。A 机本机同步和导入的实际结果见[本机验收记录](local-acceptance-a.md)；该记录不能代替 B 机参与的 M01–M05。

## 1 部署安排

| 设备 | 角色 | 运行内容 |
| --- | --- | --- |
| 本机 A | 模拟云端，同时作为工作机器 | AgentHarbor 网页、后端、PostgreSQL、MemoryCore Gateway 及其持久化数据；Codex 与本机采集／同步程序 |
| 机器 B | 接入端与工作机器 | 另一实例 Codex 与同一种采集／同步程序，连接 A 上的服务 |

两台机器先放在同一局域网。A 上供 B 使用的服务需要监听可通过局域网访问的地址，并允许所需端口的入站连接。数据库等内部服务不需要直接开放给 B。

B 使用 A 的局域网 IP 加服务端口连接，例如 `http://<A的局域网IP>:<服务端口>`；这是地址格式示意，实际地址和端口部署时填写。B 不能把 `localhost` 当作 A 的地址。

任务仍在各自机器原来的 Agent 入口启动。各 Agent 适配器将可取得的事件交给同一个本机连接程序；连接程序保存记录，再按固定周期上传到 A。云端页面不派发、启动、停止或重跑任务；本地检测频率与上传频率分开。

具体同步周期尚未确定，部署时记录实际使用的周期。跨网络连接不纳入本轮验收。

## 2 部署与验收顺序

1. 在 A 启动网页、后端、数据库和 MemoryCore Gateway，确认各自健康且记忆数据有持久化位置；MemoryCore 只供 A 后端访问。
2. 在 B 使用 A 的局域网服务地址打开网页，确认网络连通。
3. 在 A、B 分别配置采集／同步程序，并连接 A 上的服务。能打开网页不等于采集程序已经接入，需要检查实际首次上报。
4. 创建一个验收项目，将 A、B 各自的 Codex 工作目录关联到同一个项目。
5. 在两台机器分别开始真实任务，检查下一轮同步后的列表、来源与状态。
6. 检查任务结束记录、同项目记忆取回，以及 B 断网恢复后的补传。

正式启动命令、安装方式和服务端口需在实现及适配完成后提供，本文不预设尚不可用的命令。

## 3 最小验收标准

五项均通过，才算本轮最小验收通过。

| 编号 | 检查项 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| M01 | 接入与关联 | B 连接 A；两台机器关联同一个项目并完成首次上报 | 网页能区分 A · Codex 和 B · Codex；两台机器的来源归属同一个项目，不重复创建项目 |
| M02 | 自动采集任务 | 分别从 A、B 的本地 Codex 入口开始真实任务 | 无需网页派发，下一轮同步后在「任务」页看到任务、项目、机器、Agent 和最近状态 |
| M03 | 结束记录准确 | 检查真实任务结束后的上报，覆盖明确完成、中断和仅知结束的情况 | 下一轮同步后按证据更新状态；明确完成、中断、完成情况未知不混淆；发生时间与接收时间可查；仅一轮执行结束不能直接判定整项工作完成 |
| M04 | 记忆跨机复用 | A 通过 MemoryCore 为验收项目保存一条明确约定；B 从 A 取回该项目记忆并在支持的入口提供给 Codex | B 取回同项目的正确内容，取得实际提供给 Codex 的确认依据；网页能搜索到、检索命中或 Codex 继续运行本身不算通过 |
| M05 | 断网补传 | B 断网期间继续产生本地任务记录，然后恢复连接；同时检查重传和旧记录到达情况 | 未送达记录自动补传，不丢失、不重复；旧状态不覆盖新状态，保留原始发生时间和实际接收时间 |

M03 中某类情况暂时无法产生或无法取得证据时，记录为未验证，不按通过处理。M04 无法确认上下文提供结果时，记录为未确认，不把检索成功代替该项验收。

本轮通过仅证明两机 Codex 的接入。后续新增或声称支持另一种 Agent 时，应以它的实际入口重新执行适用的 M01–M05；Codex 通过不能代替其他 Agent 的验证。新增适配器应沿用现有项目关联、事件上传、暂存补传、任务页面和项目记忆查询流程；任务采集与记忆提供分别验证，不能互相推断。

## 4 验收边界

- 必须使用真实机器、真实 Agent、真实采集、真实同步和真实记忆读取；HTML 模拟数据不算通过。
- 网页只展示已经收到的记录。B 断网时保持最后已知状态和时间，不能伪装成实时状态，也不能直接断言任务失败或完成。
- 四层记忆自动提炼、额度统计和界面美化不作为本轮门槛。
- 本轮先验证局域网部署，不要求先购买或部署云服务器。
- 通过本轮后再迁移到云服务器；迁移完成与迁移后验证应单独确认，不能由本轮结果直接推断。
