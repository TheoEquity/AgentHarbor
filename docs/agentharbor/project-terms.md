# AgentHarbor 项目记忆术语

本页解释"项目记忆 → 设置"中的四个开关。设置针对当前选中的项目生效。

## 先说清楚几种内容

- **记忆素材**：智能体提出"这件事可能值得记"后提交的内容，先进入"待处理"，不会立即给后续任务使用。
- **已批准的记忆**：经确认后生效的独立条目，后续任务可以读取。
- **项目记忆**：只在所属项目内使用的记忆，例如 CIS 5480 的项目约定。
- **通用记忆**：本人在多个项目中都可能用到的记忆，例如通用工作习惯。项目是否使用它，由各项目单独决定。

## 四个开关

| 界面名称 | 简单说 | 关闭后 |
| --- | --- | --- |
| 记录记忆素材 | 允许智能体把值得记的内容先交到"待处理"，等人审核。 | 不再新增待处理素材；已有素材仍保留。任务状态同步不受影响。 |
| 更新云端记忆 | 允许把素材提交到 AgentHarbor，也允许审核素材、修改已保存的记忆。 | 新素材交不上来，也不能审核或修改记忆；已保存的内容不会被删除。 |
| 使用已批准的记忆 | 允许智能体在这个项目工作时读取已生效的项目记忆。 | 智能体暂时读不到这些记忆；内容仍保留。 |
| 同时使用通用记忆 | 读取项目记忆时，顺便读取本人可用于该项目的通用记忆。 | 仍可读取项目记忆，只是不带入通用记忆。 |

提交**新素材**需要"记录记忆素材"和"更新云端记忆"同时开启。"同时使用通用记忆"只有在"使用已批准的记忆"开启时才起作用。

例如，前三项开启、最后一项关闭时：智能体可以提交待处理素材，人可以审核和修改记忆；智能体能读取本项目已批准的记忆，但不会读取通用记忆。
